# cliq_term

## DevTools

This also comes with a DevTools extension that can be used to inspect and modify the state of all running terminals in the application.
To use the DevTools extension, you need to build the `cliq_term_devtools` package by running the following command in your terminal:

```bash
dev/build-devtool
```

Once completed, restart the frontend and open the Dart DevTools in your Browser. 
There should now be a separate tab called `cliq_term_devtools` at the top right.
